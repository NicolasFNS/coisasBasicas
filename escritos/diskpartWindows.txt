"diskpart" para acessar as ferramentas

"list disk"

"select disk x" (substitua x pelo número)

se quiser algo mais específico "list partition" para ver os números

"select partition X" (substitua X pelo número)

"delete partition" (ou "delete partition override" para forçar a exclusão de partições protegidas).

agora, se você usou "clean" provavelmente agora ele não está alocado
selecione novamente o dico certo com "select disk x" (substitua x pelo número) e siga os passos:

"create partition primary" definir o tipo da partição como Primária

"format fs=ntfs quick" escolher o tipo de sistema de arquivos

"assign letter=Z" atribui a letra
