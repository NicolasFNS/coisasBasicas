-----------------ajeitando a pasta
1. Garantir que o `httpd.conf` está com o padrão com sudo nano /etc/httpd/conf/httpd.conf

Confirme que o `DocumentRoot` e o bloco `<Directory>` estão assim:

```
DocumentRoot "/var/www/html"

<Directory "/var/www/html">
    Options Indexes FollowSymLinks
    AllowOverride All
    Require all granted
</Directory>
```

2. Ajustar se der forbidden com sudo chmod -R 755 /var/www/html/WebProjects

2.1 Corrigir o contexto SELinux com sudo restorecon -Rv /var/www/html/WebProjects

3. Reiniciar o Apache com sudo systemctl restart httpd

4. Testar com curl -I http://localhost/WebProjects/
Deve retornar `HTTP/1.1 200 OK`.


URL
'http://localhost/WebProjects/`

novos projetos, Ao criar uma nova pasta dentro de `WebProjects`:
sudo restorecon -Rv /var/www/html/WebProjects/novo-projeto

Ou, se preferir rodar de uma vez em tudo:
sudo restorecon -Rv /var/www/html/WebProjects

-----------------problemas que tive:
| 403 Forbidden | Contexto SELinux errado | `sudo restorecon -Rv /var/www/html/WebProjects` |
---
| 403 Forbidden | Permissão sem `x` | `sudo chmod 755 /var/www/html/WebProjects` |
---
| 403 "No matching DirectoryIndex" | Falta `index.html` | Criar `index.html` na pasta |
---
|Listagem não aparece | Faltando `Indexes` no `Options` | Adicionar `Indexes` no `<Directory>` e reiniciar |
---
| erro movendo arquivo | Faltando permissão de escrita numa pasta que manipula arquivos ||

sudo semanage fcontext -a -t httpd_sys_rw_content_t \
  /var/www/html/WebProjects/ProjetoWeb6/Main/ProjetoWeb/public/admin/images/products --informou ao SELinux que essa pasta pode ser alterada pelo servidor web (permissão "rw" em httpd_sys_rw_content_t)

melhor prática (pelo o pouco que pesquisei), o ideal é manter:

sudo find /pasta_projeto -type d -exec chmod 755 {} \;
sudo find /pasta_projeto -type f -exec chmod 644 {} \;

'/pasta_projeto/uploads(/.*)?'
